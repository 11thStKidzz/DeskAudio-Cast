桌面声渡 / DeskAudio Cast 0.1.11

系统要求：Windows 10 2004/build 19041 或更新的 Windows 10/11，x64，以及可互通可信网络中的兼容 HomePod。
完整包内置固定版 WebView2，无需另行安装。不要只复制 EXE；请保留整个 WebView2Fixed 目录。
MSIX 的 VCLibs Desktop 框架由商店部署；NSIS 附微软官方 VC++ x64 离线安装器，仅在缺失且征得同意后打开微软安装界面，完成后重新检查版本。拒绝、失败或检查未通过会停止安装；没有后台下载或自动重启。
不装驱动或虚拟声卡、不修改防火墙。Windows 10 的 NSIS 安装仅向内置运行时目录授予微软要求的应用容器读取/执行权限。固定运行时安全补丁需要随应用更新。

商店安装：从 Microsoft Store 安装，包签名及框架部署由商店处理。
独立安装：运行 DeskAudioCast-0.1.11-x64-setup.exe，仅安装到当前用户；本地 NSIS 未签名，Windows 可能显示安全提示，不要关闭系统安全检查。
安装不会自动启动或连接。打开程序，选择设备，开始投送，在电脑播放音频。
推荐先用均衡模式。极低延迟模式可能因网络或设备欠载而自动回退；不承诺零延迟。
关闭主窗口进入托盘，右键可调整音量、停止/继续或退出。
升级/卸载前请退出该安装目录的程序；安装器不会强制停止投送。
卸载：Windows 设置→应用→桌面声渡；独立 NSIS 也可运行安装目录 Uninstall.exe。

Requirements: Windows 10 build 19041 or later Windows 10/11, x64 and a compatible HomePod on a trusted reachable network. Complete packages include Fixed Version WebView2; no separate WebView2 installation. Keep the entire WebView2Fixed folder, not only the EXE.
MSIX declares the Store-deployed VCLibs Desktop framework. NSIS includes the official VC++ x64 offline installer, opens Microsoft's UI only with consent when needed, then rechecks the version. Cancellation, failure or failed verification stops setup. No background download or automatic restart.
No driver, virtual audio cable or firewall changes. Windows 10 NSIS grants Microsoft's required AppContainer read/execute permissions only on its bundled Runtime folder. Fixed Runtime security patches require app updates.
Install via Microsoft Store, or use DeskAudioCast-0.1.11-x64-setup.exe for current-user installation. The local NSIS installer is unsigned; do not disable Windows security checks.
Installation does not automatically launch or connect. Open the app, select a receiver, start sending and play audio on Windows.
Start with Balanced. Ultra-low mode may fall back when buffer faults are detected; zero latency is not guaranteed.
Closing the window keeps the app in the tray. Right-click for volume, stop/resume or quit.
Quit before upgrade/uninstall; the installer does not force-stop playback.
Uninstall in Windows Settings, or run Uninstall.exe for NSIS. Settings, logs, exported diagnostics and user-added files are preserved; see legal/PRIVACY.txt for clearing instructions.
